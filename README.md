# نظام إدارة الأكاديمية

نظام تشغيل بسيط وخفيف لإدارة أكاديمية تدريب حضورية: الدورات، الطلاب، التسجيلات، المدفوعات، الحضور، والشهادات — كلها من مكان واحد.

## التقنيات

- **Next.js 16** (App Router, Server Actions, TypeScript)
- **Prisma ORM** + **PostgreSQL**
- **Tailwind CSS v4** — تصميم RTL عربي بالكامل
- **pdfkit** لإصدار شهادات PDF قابلة للطباعة (مع تشكيل نص عربي عبر arabic-reshaper و bidi-js)

## التشغيل محلياً

```bash
npm install
npx prisma db push       # مزامنة قاعدة البيانات مع المخطط
npx prisma db seed       # تعبئة بيانات تجريبية (مدربون، دورات، طلاب، تسجيلات...)
npm run dev
```

ثم افتح [http://localhost:3000](http://localhost:3000).

بيانات الدخول التجريبية بعد التعبئة:

- مدير النظام: `admin@academy.com` / `password123`
- موظف: `staff@academy.com` / `password123`

## البنية

```
prisma/schema.prisma   تعريف الجداول والعلاقات
prisma/seed.ts          بيانات تجريبية
src/app/                الصفحات (App Router) + Server Actions في app/actions
src/components/ui/      مكونات واجهة قابلة لإعادة الاستخدام (Card, Table, Badge...)
src/components/forms/   نماذج الإنشاء/التعديل لكل مورد
src/lib/                Prisma client، الحسابات، التنسيق، الصلاحيات
src/lib/pdf/             توليد شهادات PDF
```

## الأقسام الرئيسية

لوحة التحكم، الدورات (مع إدارة المدربين)، الطلاب، التسجيلات، المدفوعات، الحضور (لكل يوم من أيام الدورة)، الشهادات، والإعدادات.

نظام صلاحيات بسيط بدورين ثابتين: **مدير النظام** (وصول كامل) و**موظف** (يضيف الطلاب، يسجلهم بالدورات، يسجل الدفعات والحضور، ويصدر الشهادات — بدون حذف بيانات رئيسية أو إدارة مستخدمين/إعدادات).

جميع البيانات تُقرأ وتُكتب مباشرة من/إلى قاعدة البيانات عبر Server Actions — لا بيانات وهمية في الواجهة.
